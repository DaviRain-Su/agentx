# XAgent 代币经济模型

> GPC（XAgent Protocol Credit）代币的设计决策、用途和发行计划

---

## 1. 核心决策：是否需要发代币？

### 1.1 当前立场：先用 USDC，暂不发代币

```
阶段 1（黑客松 ~ 产品成熟）:
  ✅ 使用 USDC 作为支付代币
  ✅ 无需发代币
  ✅ 用户体验简单（不需要再买一个新代币）
  ✅ 完全专注产品价值，不受代币价格波动干扰

为什么先不发:
  • 代币发行前需要足够的网络效应
  • 没有实际用途的代币 = 投机工具
  • 监管风险（SEC 等）
  • 过早发代币会分散精力
```

### 1.2 何时考虑发代币？

```
触发条件（满足任意两条）:
  □ 日活 Agent 数 > 1000
  □ 月度支付总额 > $1M USDC
  □ 去中心化治理需求出现（社区提案）
  □ 需要原生质押机制激励节点运营

预计时间线: 产品成熟后 6-12 个月
```

## 2. GPC 代币设计（未来）

如果决定发行代币，以下是初步设计框架。

### 2.1 代币用途（必须真实，不能是噱头）

```
用途 1: 协议费用折扣
  使用 GPC 支付手续费 → 享受 20% 折扣
  例: 原本 5 USDC 的任务 → 用 GPC 支付等值时只需 4 USDC 的价值

用途 2: Agent 质押
  Agent 质押 GPC 提升信任等级（见声誉系统）
  质押越多，接到高价值任务的优先级越高
  质押被 slash 作为欺诈惩罚

用途 3: 协议治理
  持有 GPC → 对协议参数投票
  例: 平台手续费率、新链接入、Agent 审核标准

用途 4: 网络激励
  早期参与者（节点运营商）获得 GPC 奖励
  优质 Agent（声誉 > 80）每月获得 GPC 奖励
  长期持有用户的忠诚度奖励
```

### 2.2 代币分配

```
总量: 1,000,000,000 GPC（10 亿）

分配:
  生态激励         35%  350M GPC  — 长期释放，激励高质量 Agent 和用户
  团队与顾问       20%  200M GPC  — 4年线性解锁，1年锁仓期
  协议金库         20%  200M GPC  — 由 DAO 控制，用于生态建设
  私募轮（投资人）  15%  150M GPC  — 2年线性解锁
  公募 / IDO       10%  100M GPC  — 流动性启动

释放计划:
  Year 1: 15%（主要是公募 + 部分团队解锁）
  Year 2: 25%（生态激励开始大量释放）
  Year 3: 30%（增长期，激励深化）
  Year 4+: 30%（协议成熟阶段）
```

### 2.3 价值捕获机制

```
协议手续费流向:
  总费用 = 任务预算的 5%（协议费，Agent 费用另算）

  其中:
    40% → 销毁 GPC（通缩）
    40% → 质押者分红（以 USDC 分配）
    20% → 协议金库（开发基金）

这创造了 GPC 价值捕获循环:
  协议使用量↑ → 手续费收入↑ → 销毁量↑ → 流通量↓ → 价格↑
```

## 3. 竞品代币模型对比

| 项目 | 代币 | 主要用途 | 评价 |
|------|------|---------|------|
| Fetch.ai | FET | 质押 + 服务支付 | 代币必须，但用户体验差 |
| Autonolas | OLAS | 服务注册 + 质押 | 设计合理，门槛高 |
| Bittensor | TAO | 挖矿奖励 | 高度投机化 |
| **XAgent** | GPC（未来） | 折扣 + 质押 + 治理 | 先 USDC，代币是增强而非必须 |

**核心差异化**：USDC 先行，GPC 作为加速器。用户不需要代币也能使用协议，但用代币可以省钱。

## 4. 黑客松阶段的经济模型

在代币发行前，XAgent 的经济模型完全基于 USDC：

```
收入来源:
  协议手续费: 每个任务预算的 3%（黑客松后启用）
  例: 用户支付 10 USDC → XAgent 收 0.3 USDC，Agent 收 9.7 USDC

早期增长策略:
  • 前 6 个月免协议手续费（吸引用户和 Agent）
  • 高质量 Agent 获得"早期贡献者"身份（未来 GPC 空投优先权）
  • 工作流模板免费使用，执行付费

成本结构:
  • Cloudflare Workers: ~$0.0001/Agent 执行
  • CF AI Gateway: 按 token 计费（Workers AI 免费）
  • X Layer gas: 极低（OKX 链）

  → 每次 Agent 执行的平台成本约 $0.001-0.005
  → 对应用户支付 0.1-5 USDC 的服务费
  → 毛利润 95%+（早期）
```
